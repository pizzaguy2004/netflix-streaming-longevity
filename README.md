# Netflix Streaming Longevity Analysis

## Project Overview
This project analyzes the key factors driving the chart longevity of TV shows on Netflix. By combining historical weekly global chart data from Netflix with external metadata from The Movie Database (TMDB) and IMDb, we apply exploratory data analysis, survival analysis, and statistical regression to quantify how content characteristics (such as genre, runtime, episode count, and season count) and audience ratings influence how long a show remains in the Global Top 10.

## Research Questions
* **Question 1:** Which structural content features (e.g., genre tag, episode count, season count) and audience feedback signals (e.g., rating score, review volume) most significantly influence how many weeks a TV show remains in the Netflix Global Top 10?
* **Question 2:** Do multi-season TV shows sustain chart longevity longer than single-season limited series, and does higher audience rating help prevent viewer decay across subsequent seasons?

## Project Goals
* **Model Retention:** Apply statistical modeling and survival analysis (Kaplan-Meier estimates, Cox Proportional Hazards) to evaluate show decay off weekly charts over time.
* **Identify Key Predictors:** Measure the marginal impact of structural attributes (genre, episode count, season count) and audience feedback (ratings, review volume) on chart duration.
* **Data Integration:** Maintain an automated, reproducible data pipeline merging weekly streaming performance with API and bulk metadata.

## File & Directory Reference

### Python Code Scripts
* **`fetch_tmdb_metadata.py`** 
    Downloads the official Netflix TSV dataset (if not present) and queries the TMDB REST API to extract metadata (genres, episode/season counts, ratings, original language) for all unique TV titles.
* **`build_master_dataset.py`** 
    Aggregates weekly records from `all-weeks-global.tsv` to calculate each show's maximum chart longevity (`Y = max_weeks`), merges it with TMDB metadata (`X`), cleans missing values, and exports `master_netflix_analysis.csv`.
* **`eda_presentation1.py`**  
    Computes summary statistics ($N$, mean, standard deviation, min/max) and exports high-resolution figures into the `plots/` directory for presentation slides.

### Data Files (`data/`)
* **`data/all-weeks-global.tsv`**  
  * Official Netflix Top 10 portal (`top10.netflix.com`).  
  * **Description:** Raw tab-separated dataset containing weekly historical performance records (weekly rank, cumulative weeks in Top 10, weekly hours viewed) for all global Netflix titles.
* **`data/netflix_tmdb_metadata.csv`**  
  * Generated by `fetch_tmdb_metadata.py` via TMDB API (`api.themoviedb.org`).  
  * **Description:** Extracted show-level features including vote average, vote count, total episodes, total seasons, primary language, and genre tags.
* **`data/master_netflix_analysis.csv`**  
  * Generated by `build_master_dataset.py`.  
  * **Description:** The finalized master modeling dataset containing 1,220 unique TV shows with matched outcomes ($Y$) and predictor features ($X$).
* **`data/title.basics.tsv`**  
  * **Source:** IMDb Non-Commercial Datasets (`datasets.imdbws.com`).  
  * **Description:** Raw IMDb bulk dataset containing title metadata (genres, start/end year, runtime minutes).
* **`data/title.episode.tsv`**  
  * **Source:** IMDb Non-Commercial Datasets (`datasets.imdbws.com`).  
  * **Description:** Raw IMDb bulk dataset mapping parent series IDs to individual episode season numbers and episode numbers.
